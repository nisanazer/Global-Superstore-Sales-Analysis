# Global Superstore Sales Analysis

This project focuses on analyzing Global Superstore sales data using Power BI. The dataset contains sales, profit, orders, quantity, region, market, and shipping details.

An interactive dashboard was created using Card visuals to display key metrics such as Total Sales, Total Profit, Total Orders, and Total Quantity. Different charts and filters were also used to analyze business performance.

The main objective of this project is to understand sales trends and gain useful business insights through data visualization.
